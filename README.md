# Ubuntu Core Image Builder

This is a frontend application for ubuntu-image, allowing to use the known options to build Ubuntu Core images.

## Getting Started

Launch the app, pick a model assertion, pick an output dir, go to the Build page of the app and click the build button.
You should find the produced image in the output dir you picked.

## Building

Clone this tree and run 
```
flutter build linux
```
You will find the application in the build/linux/x64/release/bundle/ directory

To run the code directly without building an app bundle:
```
flutter run linux
```
